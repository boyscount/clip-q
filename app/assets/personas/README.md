# ช็อตคนสำหรับแทรกในคลิป

สร้างโฟลเดอร์ชื่อเดียวกับ "ตัวละคร" ที่เลือกในแอป แล้ววางไฟล์ลงไป

    app/assets/personas/
      น้องมายด์ สายบิวตี้/
        01.jpg      ถือสินค้าให้เห็นหน้า
        02.mp4      ทาแล้วยิ้ม สั้น ๆ 3-5 วินาที
        03.jpg      ชี้ป้ายราคา

รับทั้งรูป (.jpg .png .webp) และคลิปสั้น (.mp4 .mov .webm)
เรียงตามชื่อไฟล์ ตั้ง 01, 02, 03 … ไว้จะคุมลำดับได้

## ถ่ายยังไงให้ใช้ได้ดี

- **ถ่ายแนวตั้ง** ระบบครอปเต็มเฟรม 9:16 ถ้าถ่ายแนวนอนจะโดนตัดข้างเยอะ
- **ไม่ต้องพูด** เสียงมาจาก TTS อยู่แล้ว เอาแค่ภาพ
- คลิปสั้น 3-5 วินาทีพอ ถ้าช่องที่ต้องเติมยาวกว่า ระบบจะวนซ้ำให้เอง
- เว้นที่หัวและท้ายเฟรมไว้ เพราะมีป้ายราคาด้านบนและซับด้านล่างทับ

## ระบบเรียงให้ยังไง

เปิดด้วยคน ตรงกลางเป็นสินค้า ปิดท้ายด้วยคนตอนพูด CTA
คนได้ราวหนึ่งในสามของช็อตทั้งหมด ไม่เกินจำนวนไฟล์ที่มีจริง

ไม่มีโฟลเดอร์ = ไม่มีช็อตคน คลิปยังเรนเดอร์ได้ตามปกติด้วยภาพสินค้าล้วน

## ไฟล์ในนี้ไม่ขึ้น git

เป็นรูปและคลิปของคุณเอง  กันไว้แล้ว เหลือแค่ไฟล์ README นี้
